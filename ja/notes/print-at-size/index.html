NORI NOTES / 小さな制作

印刷したステッカーが小さくなる理由

作成・確認：2026年10月22日 · NORI Tools

画面で40 × 60mmにしても、印刷では小さくなることがあります。ファイル寸法だけでなく、倍率やプリンター余白も結果に影響します。

「ページに合わせる」より「100%」

「ページに合わせる」は印刷可能範囲に収めるため拡大縮小します。正確な寸法には「実際のサイズ」か「100%」を選び、ヘッダー・フッターをオフにし、用紙サイズと向きを合わせてください。

用紙の端まで印刷できますか？

印刷できない端の領域は機種ごとに違います。余白0mmでもフチなしになるとは限りません。説明書を確認して余白を確保し、切り離すならステッカー間の隙間も残しましょう。

回転で必要枚数が変わります

A4に四辺10mm余白、間隔3mmで40 × 60mmを並べると4列×4行で16枚。90度回転すると3列×6行で18枚入り、50枚作るにはそれぞれ用紙4枚と3枚です。ノリは同じ向きの格子配置を2方向で比較し、向きを混ぜる最適化はしません。

まず1枚で試しましょう

  1. プレビューで用紙とステッカーのサイズを確認。
  2. SVGまたは印刷機能で最初の1枚を100%印刷。
  3. 定規で枠の縦横を測る。
  4. 寸法と余白を確認してから必要枚数を印刷。

配置ヘルパーは寸法・枚数・裁断枠を計画し、選んだ1枚の画像を繰り返し並べます。工房のPNGも使えます。カッティングマシン専用形式には対応しません。

無料取引明細書の作り方と見積書からの切り替え

作成・確認：2026年11月4日 · NORI Tools · 日本語ガイド

ノリツールズの取引明細書に取引日・品目・数量・金額を入力し、PDF保存する方法です。

無料で取引明細書を作成 ↗

ノリ見積書には取引明細書の様式もあります。ソフトをインストールせず文書の種類を切り替えて品目と金額を整理できます。登録不要で無料作成・印刷・PDF保存が可能です。

見積書と取引明細書の使い分け

取引前の提案には見積書、実際の取引内容の整理には取引明細書を使います。同じ編集画面なので、供給者や品目を入力し直さず切り替えられます。

1.「文書の種類」で取引明細書を選ぶ

上部で取引明細書を選び、タイトルと案内が変わることを確認します。既存の内容があれば、実際の取引日・数量・単価に合わせてください。種類を切り替えても取引内容が自動確定するわけではありません。

2. 実際の取引情報を入力する

  1. 供給者の商号・登録番号・担当者と取引先名を入力します。
  2. 取引日と文書番号を確認します。
  3. 実際に提供した品目・規格・数量・単価を入力します。
  4. 税込・税別と合計を確認します。
  5. 補足事項は備考に記入します。

例えば包装用シール50枚と案内カード100枚は別々の行に記入します。規格や単価が異なるものを分けると、後で確認しやすくなります。

3. 残金の表示方法も確認する

残金がなければ「残金なし」を選びます。必要なら上部合計への加算か別表示を選べます。当取引額と残金を混同しないよう、保存前に上下の金額を確認してください。

4. PDF保存とファイル名の整理

「固定PDF保存」または「印刷／PDF保存」を使います。2026-11-04_NoriShop_Statement.pdfのように日付と取引先を付けると探しやすくなります。下部にはノリツールズで無料作成した旨の小さな表記が入ります。

よく使う供給者と文書の保存

供給者情報や現在の文書を、この端末のブラウザに保存できます。別の端末でも使う場合はバックアップか編集可能ファイルを保存してください。再読み込み前に保存済みか確認しましょう。

電子税金計算書を発行できる？

いいえ。見積書・取引明細書を作成・保存するツールです。電子税金計算書の発行や税務申告には対応していません。

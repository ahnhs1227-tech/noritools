무료 이력서 작성부터 PDF 저장까지

작성·확인 2026년 11월 4일 · NORI Tools · 한국어 가이드

이력서에 직접 입력하고 사진 첨부·행 순서 변경·모바일 화면 맞춤을 활용해 A4 PDF로 저장하는 방법입니다.

무료 이력서 작성하기 ↗

이력서 파일을 내려받았는데 편집 프로그램이 없거나 표가 틀어질 때가 있죠. 노리 이력서는 웹페이지에 보이는 이력서의 빈칸을 눌러 직접 작성하는 무료 도구예요. 회원가입이나 프로그램 설치 없이 시작하고, 마지막에 인쇄 창에서 PDF로 저장합니다.

작성 전에 준비할 것

  • 이름, 연락처, 이메일과 제출처에서 요구하는 기본 정보
  • 학교·회사 이름, 재학·재직 기간, 맡았던 업무
  • 사진이 필요한 경우 10MB 이하 JPG·PNG·WebP 파일

화면이 넓은 PC에서 작성하면 표 전체를 보며 긴 내용을 입력하기 편해요. 한국어 모바일 화면에서는 문서 위의 ‘화면에 맞춤’과 ‘크게 보기’를 이용해 전체 확인과 확대 입력을 전환할 수 있습니다.

모바일에서는 전체 확인과 확대 입력을 나눠서 해요

  1. 처음에는 ‘화면에 맞춤’이 선택되어 문서 전체 너비가 화면에 들어오도록 작게 표시됩니다. 문서 아래쪽은 세로로 내려서 확인하세요.
  2. 글자가 작아 입력하기 어렵다면 ‘크게 보기’를 누르세요. 확대된 문서 안에서 좌우로 움직여 원하는 칸을 누를 수 있습니다.
  3. 입력을 마치면 ‘화면에 맞춤’으로 돌아와 전체 배치를 확인하세요. 보기 전환은 작성한 내용을 바꾸지 않습니다.

이 버튼은 현재 한국어 모바일 화면에 적용되어 있어요. 화면에 표시되는 배율은 편집 화면용이며, PDF의 용지 크기나 인쇄 배율을 바꾸지 않습니다.

1. 필요한 항목만 선택해요

상단의 ‘표시할 카테고리’에서 병역 및 보훈사항, 학력사항, 경력사항, 개인능력을 선택하세요. 사용하지 않는 항목을 끄면 편집 화면과 출력물에서 함께 숨겨집니다. 학력과 경력을 따로 적는 ‘분리 작성’과 한 표에 적는 ‘통합 작성’ 중에서 먼저 선택해 주세요.

두 작성 방식의 입력 내용은 자동으로 합쳐지거나 옮겨지지 않습니다. 작성 중 방식을 바꿨을 때 표가 비어 보이면 원래 방식으로 돌아가세요. 같은 페이지를 열어둔 동안에는 원래 입력 내용이 남아 있습니다. 인쇄에는 현재 선택한 작성 방식이 적용됩니다.

‘선택 정보’에서는 생년월일·주민등록번호 중 표시할 항목과 SNS 표시 여부를 고를 수 있어요. 제출처에서 요구하는 항목을 확인하고 필요한 정보만 입력하세요.

2. 이력서의 빈칸을 눌러 작성해요

성명·연락처·학력·경력 등 이력서 안의 빈칸을 눌러 본인의 정보를 입력하세요. 연한 회색의 ‘김노리’, ‘Kim Nori’ 등은 입력 위치를 알려주는 예시이며 실제로 작성된 내용이 아닙니다. 입력하지 않은 예시는 출력물에 포함되지 않아요.

사진은 이력서 안의 ‘사진 넣기’를 눌러 10MB 이하 JPG·PNG·WebP 파일을 선택하세요. 사진이 들어간 영역을 다시 누르면 다른 사진으로 바꿀 수 있고, ‘사진 지우기’로 제거할 수도 있어요. 사진은 칸을 채우도록 표시되므로 얼굴이 잘리지 않았는지 확인해 주세요. 현재 이력서 안에는 사진 위치·확대·자르기 조절 기능이 없습니다.

3. 학력과 경력의 순서를 맞춰요

표 아래의 ‘＋ 학력사항 추가’ 또는 ‘＋ 경력사항 추가’로 행을 늘리세요. 순서가 뒤섞였다면 각 행 오른쪽의 ↑·↓ 버튼으로 한 줄씩 옮길 수 있어요. 학력·경력뿐 아니라 통합 작성 표와 개인능력 표에서도 같은 방식으로 순서를 바꿀 수 있습니다.

× 버튼은 해당 행을 삭제합니다. 입력한 내용이 있는 행은 삭제 전에 확인창이 뜨며, 마지막 한 행은 삭제할 수 없어요. 첫 행의 ↑와 마지막 행의 ↓는 비활성화됩니다. 이동·삭제 버튼은 편집용으로, 출력물에는 포함되지 않습니다.

자동 날짜 정렬 기능은 아니에요. 최근 경력부터 적기로 했다면 모든 행에 같은 기준을 적용해 직접 순서를 맞춰 주세요.

4. A4 PDF로 저장해요

  1. 상단 ‘인쇄 · PDF 저장’을 누릅니다.
  2. 브라우저 인쇄 창에서 대상을 ‘PDF로 저장’으로 선택합니다. 기기에 따라 이름이 다를 수 있어요.
  3. 설정 항목이 제공되는 브라우저에서는 용지를 A4, 배율을 100%로 맞추고 머리글·바닥글을 끕니다.
  4. 미리보기에서 글자가 잘리거나 빈 페이지가 생기지 않는지 확인한 뒤 저장합니다.

모바일에서는 기기와 브라우저에 따라 인쇄·PDF 저장 메뉴가 다를 수 있어요. 메뉴가 없거나 저장이 어렵다면 PC 브라우저에서 작성·저장하는 방법을 권장합니다. 현재 작성 내용을 다른 기기로 자동으로 이어주는 기능은 없으므로, PC로 이동할 계획이라면 긴 내용을 입력하기 전에 저장 메뉴부터 확인해 주세요.

제출 전 확인할 것

연락처와 이메일의 오타, 날짜 순서, 사진 방향을 확인하세요. 길게 쓴 내용은 실제 인쇄 미리보기에서 한 번 더 확인하는 것이 좋아요. 출력물 하단에는 노리툴즈 무료 제작 안내 문구가 작게 포함됩니다.

작성 중인 내용이 자동 저장되나요?

아니요. 이력서 정보와 사진은 현재 브라우저에서 처리하며 자동 저장되지 않습니다. 새로고침하거나 탭을 닫기 전에 PDF를 저장하세요. 작성한 내용이 있으면 ‘새로 작성’이나 홈으로 이동할 때 확인창이 뜨지만, 이것이 임시 저장을 뜻하지는 않습니다. PDF는 제출·인쇄용 결과물이며, 다시 불러와 이 도구에서 편집하는 파일 형식은 아닙니다. 현재는 편집 가능한 초안 파일 저장·불러오기와 기기 간 이어쓰기를 지원하지 않아요.

입력한 정보와 사진

NORI Tools는 별도의 회원가입 없이 사용할 수 있습니다. 계산기에 입력한 숫자·문장·레시피와 업로드한 사진은 현재 브라우저에서 처리하며 도구 기능을 위해 별도 서버로 전송하거나 저장하지 않습니다. 새로고침하거나 페이지를 닫으면 작업 내용이 사라질 수 있어요. 파일 저장·복사·공유는 사용자가 직접 선택했을 때만 수행됩니다.

브라우저 저장소

즐겨찾기로 선택한 도구 ID를 이 기기의 localStorage에 저장합니다. 이 정보는 NORI 서버로 보내지 않습니다. 배경 제거 모델은 반복 다운로드를 줄이기 위해 브라우저 캐시에 보관할 수 있습니다. 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있어요. 브라우저나 기기를 바꾸면 즐겨찾기가 공유되지 않습니다.

외부 다운로드와 호스팅

사이트는 GitHub Pages에서 제공됩니다. 사이트 접속과 외부 파일 다운로드 때에는 해당 서비스에 IP 주소·접속 시각·브라우저 정보 등 일반적인 요청 정보가 전달될 수 있습니다. 배경 제거 엔진은 jsDelivr, 정밀 U²-Net 모델은 Hugging Face에서 받아오고 빠른 모델은 이 사이트에서 받습니다. 이 요청에 업로드한 사진이나 도구 입력값은 포함하지 않습니다.

GitHub 개인정보 안내 · jsDelivr 개인정보 안내 · Hugging Face 개인정보 안내

광고와 분석

현재 NORI Tools에는 Google AdSense 광고 코드나 별도의 방문 분석 코드를 설치하지 않았습니다. 광고를 도입할 경우 제공 사업자·쿠키·맞춤 광고·동의 절차 등 실제 설정에 맞춰 이 방침을 먼저 업데이트합니다.

이메일 문의

문의 메일을 보내면 사용자가 작성한 이메일 주소와 문의 내용이 이메일 서비스에 전달됩니다. 민감한 개인정보나 원본 사진을 포함할 필요는 없습니다. 문의 목적에 필요한 범위에서 내용을 확인합니다.

노리 놀이터 기록

게임 최고 점수, 카드 게임 난이도별 최소 이동 횟수와 완료 시간, 소리 켜짐 설정을 브라우저의 로컬 저장소에 보관합니다. 이 기록은 서버로 전송되지 않으며 다른 기기와 동기화되지 않습니다. 브라우저의 사이트 데이터를 지우면 함께 삭제됩니다.

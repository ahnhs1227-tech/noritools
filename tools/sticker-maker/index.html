이름표부터 감사 스티커까지

모양과 노리를 고르고 문구를 적어보세요. 개인 사진을 추가하면 사진 옆에 작은 노리가 함께 들어가요. 긴 문구는 스티커 안에 들어가도록 자동으로 작아집니다. 사진은 잘라내지 않고 비율을 유지해 넣어요.

만든 스티커를 종이에 배치하려면

‘인쇄할 종이에 배치하기’를 누르면 지금 만든 디자인을 배치 도우미로 넘깁니다. 스티커 크기와 수량을 정한 다음 실제 크기 인쇄나 PDF로 저장하세요. 페이지 사이 전달이 안 되면 PNG로 저장한 뒤 배치 도우미에서 다시 선택할 수 있어요.

사진과 문구는 어디에 저장되나요?

사진은 서버로 보내지 않습니다. 공방의 작업은 새로고침하면 사라져요. 배치하기를 선택한 경우에만 완성 이미지 한 장을 이 탭의 임시 저장소에 넣고, 배치 도우미에서 읽은 뒤 지웁니다.

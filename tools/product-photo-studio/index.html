사진 한 장을 바로 올릴 수 있게

① 사진 선택 → ② 사진 다듬기 → ③ 배경색·여백·크기 조절 → ④ 이미지 저장 순서로 사용해요. 배경을 지운 피사체의 범위를 찾아 화면 가운데에 놓습니다. 이미 배경이 투명한 PNG라면 ‘배경 자동 제거’를 끄고도 여백을 정리할 수 있어요.

투명 배경과 흰색 배경

체크무늬는 투명한 부분을 보여주는 화면 표시이며 저장 파일에는 들어가지 않아요. PNG와 WebP는 투명도를 유지합니다. JPG는 투명도를 지원하지 않아 투명 배경을 선택해도 흰색으로 저장해요.

용량을 줄이고 싶다면

JPG 또는 WebP를 선택하고 목표 용량을 입력하면 화질을 조정해 상한 안에 맞춰봅니다. 가장 낮은 품질에서도 상한을 넘으면 실제 용량을 안내해요. 더 작은 크기로 줄여 다시 저장할 수 있습니다. PNG는 무손실로 저장하므로 목표 용량을 강제로 적용하지 않습니다.

처리 방식과 한계

사용자 사진은 서버로 보내지 않습니다. 첫 사용 시 처리 엔진은 jsDelivr에서, 정밀 모델은 Hugging Face에서, 빠른 모델은 이 사이트에서 내려받아요. 주요 피사체가 뚜렷할수록 결과가 좋아요. 가는 머리카락·반투명 물체·복잡한 배경은 일부가 남거나 지워질 수 있어 결과를 확인한 뒤 사용해 주세요. 수동 지우개·복원 기능은 포함하지 않습니다.

안정적인 모바일 처리를 위해 원본은 긴 변 최대 2,048px로 줄여 처리하며 원본 파일을 변경하지 않습니다. 애니메이션은 정지 이미지로 처리해요. 모델 준비 중에는 Wi-Fi 사용을 권장합니다.

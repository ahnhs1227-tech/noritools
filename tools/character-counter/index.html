공백 포함과 제외는 무엇이 다른가요?

공백 포함은 띄어쓰기와 줄바꿈까지 세고, 공백 제외는 실제 문자만 셉니다. 제출 기준이 다를 수 있으니 요구사항을 먼저 확인하세요.

안심하고 사용하세요

입력한 글은 서버로 전송하거나 저장하지 않고 현재 브라우저에서만 계산합니다.

자주 묻는 질문

한글은 몇 바이트인가요?

UTF-8 기준 한글 한 글자는 일반적으로 3바이트입니다.

줄바꿈도 글자 수에 포함되나요?

공백 포함 수에는 줄바꿈 문자도 포함됩니다.

입력한 글이 저장되나요?

아니요. 이 도구는 입력 내용을 저장하거나 전송하지 않습니다.

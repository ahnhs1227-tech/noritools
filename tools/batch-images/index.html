JPG의 투명한 부분은 흰색으로 채워요. 작은 원본은 확대하지 않아요.

ZIP 파일 다운로드 ↓

휴대폰에서는 각 사진의 ‘저장’ 버튼을 이용해도 좋아요. ZIP은 파일 앱에서 압축을 풀어 사용하세요. 카카오톡 안에서 저장이 안 되면 Chrome이나 삼성 인터넷에서 다시 열어주세요.

선택한 사진 저장

한 장씩, 차근차근 처리해요

선택한 사진은 원본 비율을 유지해 긴 변 기준으로 줄입니다. 작은 사진을 억지로 확대하지 않아요. 원본 파일은 그대로 두고 이름 뒤에 ‘nori’를 붙인 새 파일을 만들어요. 같은 이름의 사진도 번호를 붙여 구분합니다.

파일 형식 고르기

사진 용량을 줄이려면 JPG나 WebP를, 투명도를 유지하며 손실 없이 저장하려면 PNG를 선택하세요. 품질과 이미지 내용에 따라 원본보다 용량이 커질 수도 있습니다. 애니메이션은 한 장의 정지 이미지로 저장하며, 최대 4,000만 화소까지 지원합니다.

안심하고 정리하세요

이미지는 브라우저 안에서만 처리합니다. 모바일 메모리 사용을 줄이기 위해 한 장씩 처리하고 결과 합계는 120 MB까지 보관해요. 처리 도중 중지해도 이미 완성한 사진은 저장할 수 있습니다. 크기·형식·품질을 바꾸면 이전 결과를 지우므로 먼저 저장해 주세요.
